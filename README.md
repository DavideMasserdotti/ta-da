# Ta-Da

Ta-Da è una semplice to-do list pensata per gestire task con posizione spaziale.

## Stack tecnologico

- **Frontend:** Next.js  
- **Backend:** Spring Boot  
- **Database:** PostgreSQL  

## UI e componenti

Per la parte visuale dell’applicazione sono state utilizzate:

- **HeroUI**:  
  https://www.heroui.com/
- **Magic UI**:  
  https://magicui.design/

## Funzionalità principali

- Creazione, modifica e archiviazione di task.  
- Associazione di ogni task a una posizione geografica (latitudine/longitudine).  
- Visualizzazione e gestione dei task tramite interfaccia web reattiva.
- Possibilità di ricercare tra i task filtrando sul nome.
- Possibilità di ordinare la lista di task per diverse caratteristiche.
